GAME 2 — CHAIN GAME

A word chain game using real NBA player names.

Rules:

	•	Game starts with a displayed NBA player name
	•	Player must type a real NBA player whose first name starts with the last letter of the previous player’s last name
	•	Example: Michael Jordan → last name Jordan ends in N → next player must start with N → Nikola Jokic → last name Jokic ends in C → next must start with C → Carmelo Anthony
	•	30 second timer per entry
	•	App validates entries against a database of real NBA players — invalid names or wrong starting letter end the game
	•	Score = length of chain before error or timeout
	•	Solo mode tracks personal best and global leaderboard
	•	Multiplayer mode — pass the device, player who breaks the chain loses
