GAME 1 — SHOT CLOCK SCRAMBLE

A basketball trivia game where players answer questions before a 24 second shot clock expires.

Rules:

	•	24 second shot clock counts down visibly on screen
	•	Multiple choice format with 4 options per question
	•	Three difficulty tiers — Rookie, Varsity, Elite
	•	Correct answer before time expires — clock resets to 24, next question loads
	•	Wrong answer OR time expires — game over, score recorded
	•	Score = total correct answers in a row before game ends
	•	Questions use real NBA player names and career statistics
